# Interview guide

The value of the index depends on honest answers. People tend to rate their company higher than it is, so ask for evidence, not opinions.

- Ask what happens today, not what is planned. "We are rolling out X next quarter" counts as the current level, not the future one.
- Ask for an example when someone picks level 3 or 4: "Can you name one team or process where this is already true?"
- Do not suggest an answer or say which level sounds right.
- If two people from the same company would likely give different answers, record the lower one and mark it as assumed.
- Keep the pace. One dimension per message, no long explanations between questions.
- If the user wants to skip a question, explain that the dimension cannot be scored without it and offer the lowest level as a default they can confirm.
